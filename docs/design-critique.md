# ASL — Final Design Critique

ROUND 1
Seen in one second: a Filipino Y2K computer booting into a museum.
Idea (one sentence): the early-2000s Filipino family computer becomes the museum building, so opening windows is the act of visiting exhibits.
Live thing: the visitor opens a Nokia-style inbox, chooses text messages, and moves between guided and free-exploration modes.
Layout words by section: boot=poster / welcome=dialog / desktop=workspace / rooms=explorer / Nokia=inbox / chats=split archive
Scores: design 6.5 · usability 8.0 · creativity 8.4 · content 8.3 → overall 7.5
Caps applied: design capped at 6.5 because the submission deliberately contains no licensed archival photography or footage.
Top three problems (most visible first), each with the screenshot it shows in and the fix:
1. `desktop-fold.jpg`: the boot composition is distinctive, but the archival promise is carried by original interface art rather than period photography. Fix after submission only when the group has verified reusable images and documented each license in `asset-credits.md`.
2. `tablet-fold.jpg`: the boot cluster sits high enough to leave a broad quiet area below it. Keep this as breathing room for the desktop-first poster, or reduce the stage height if the final classroom display uses a shorter viewport.
3. `mobile-fold.jpg`: the phone view is an honest recommendation card instead of the full museum. This is intentional scope control; a future version could turn the rooms into a touch-first vertical tour without squeezing the desktop metaphor.

Final direction: “The page is the object.” The operating-system shell is not decoration around the museum; it is the museum’s architecture. Restrained movement, strong keyboard behavior, and a single open window keep the idea understandable instead of turning it into a desktop simulator.
